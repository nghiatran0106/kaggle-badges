# 12 · Fork notebook → Code Forker

Chỉ làm được trên web (CLI push không gắn "fork parent").
1. Mở một notebook public tốt, ví dụ notebook top của Titanic hoặc S6E10 (tab Code → sort Most Votes).
2. Bấm **Copy & Edit**.
3. **Sửa ít nhất 1 thứ** (thêm feature, đổi model, thêm ô markdown ghi chú bạn học được gì).
4. **Save Version** (Save & Run All).

Gợi ý học: fork notebook điểm cao nhất của S6E10, đọc kỹ, ghi lại 3 kỹ thuật vào `notes.md` ở thư mục này, rồi áp dụng vào `02-playground-s6e10/src`.
