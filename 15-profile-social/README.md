# 15 · Profile & cộng đồng (chỉ làm trên web, khoảng 15 phút)

- [ ] **Stylish**: Profile → Edit: ảnh đại diện, tagline, bio, và **pin** 1 item (ví dụ dataset ConnectX hoặc notebook RSNA).
- [ ] **Collector**: Your Work → **Collections → New Collection** (ví dụ "Badge projects"), thêm vài item.
- [ ] **Bookmarker**: bấm bookmark (🔖) ở bất kỳ notebook, dataset hay cuộc thi nào.
- [ ] **Agent of Discord**: vào discord.gg/kaggle → làm theo kênh xác minh để **link tài khoản Kaggle** (Kaggle → Settings → *Discord* nếu có).
