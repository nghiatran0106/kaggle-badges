# 11 · GitHub → Github Coder · Linked Dataset Creator · Linked Model Creator

Ba badge này đều cần repo **public** trên GitHub, nên làm sau khi bạn push repo `kaggle-badges` (xem `PROCEDURE.md` §3).

| Badge | Làm trên web |
|---|---|
| **Github Coder** | Kaggle → Create → New Notebook → **File → Import Notebook → tab GitHub** → chọn `nghiatran0106/kaggle-badges` → `11-github-linked/notebooks/connectx_first_player.ipynb`. (Hoặc trong notebook bất kỳ: File → Link to GitHub.) Save Version. |
| **Linked Dataset Creator** | Kaggle → Create → New Dataset → **Link (🔗) / GitHub** → dán `https://github.com/nghiatran0106/kaggle-badges` hoặc raw URL `https://raw.githubusercontent.com/nghiatran0106/kaggle-badges/main/11-github-linked/dataset/connectx_games.csv` → Create. |
| **Linked Model Creator** | Kaggle → Create → New Model → khi upload variation chọn **Link / GitHub / URL** → dán URL repo → Create. |

Notebook trong `notebooks/` đọc CSV qua raw URL của GitHub, nên khi chạy trên Kaggle phải bật Internet.
